# 🏫 Oumou Salamat - School Management SaaS

Application fullstack de gestion d’école (SaaS) développée avec :

- ⚙️ Backend : NestJS + Prisma + PostgreSQL
- 🎨 Frontend : React + Vite + TypeScript
- 🐳 Docker pour l’environnement local
- 🔐 Authentification JWT (en cours)
- 👨‍🏫 Gestion multi-rôles : Admin / Professeur / Parent / Gestionnaire

---

## 🎯 Objectif du projet

Cette plateforme permet de gérer :

- 👨‍🎓 Les élèves
- 👨‍🏫 Les professeurs
- 👨‍👩‍👧 Les parents
- 🏫 L’administration de l’école
- 📊 Les notes et suivis scolaires
